# muis

یک پخش‌کننده‌ی موسیقی فارسی. جستجو، پخش، متن ترانه، و اشتراک‌گذاری پلی‌لیست بین دستگاه‌ها.

## راه‌اندازی

```bash
bun install
bun run dev
```

همین. **هیچ تنظیمی لازم نیست** — نه کلید API، نه حسابی در سرویس دیگر، نه نصب پایگاه‌داده. یک
کلون تازه از این مخزن بالا می‌آید و کار می‌کند.

پیش‌نیاز: [Bun](https://bun.sh) ۱.۴ یا بالاتر (یا Node ۲۲.۵ به بالا).

## داده کجاست

حساب‌ها و پلی‌لیست‌های اشتراکی در یک پایگاه‌داده‌ی SQLite هستند. کجا، بستگی دارد کجا اجرا
می‌شود:

| کجا اجرا می‌شود | کجاست | چطور |
| --- | --- | --- |
| دسکتاپ و پریویو | `.data/muis.sqlite` | خودکار در نخستین درخواست ساخته می‌شود |
| ورکر منتشرشده‌ی Cloudflare | پایگاه‌داده‌ی D1 | با یک binding در `wrangler.jsonc` |

روی ورکر Cloudflare دیسک ماندگاری وجود ندارد، پس فایل بعد از هر راه‌اندازی دوباره پاک
می‌شود. اگر `d1_databases` در `wrangler.jsonc` فعال باشد، برنامه همان‌جا از D1
می‌خواند و همان‌جا می‌نویسد. تا وقتی آن binding نباشد، برنامه صریح می‌گوید حساب‌ها در آن
نسخه در دسترس نیستند — به‌جای اینکه ثبت‌نامی بپذیرد که بی‌صدا پاک شود.

## بکاپ

```bash
bun run backup                              # می‌سازد
bun run restore .data/backups/muis-....sqlite
```

بکاپ‌ها در `.data/backups/` می‌نشینند. بازگردانی، نسخه‌ی فعلی را کنار می‌گذارد و پس از آن باید
سرور را دوباره راه‌اندازی کنی.

## چه چیزی در گیت هست و چه چیزی نیست

**هست:** کل کد، `bun.lock`، اسکیمای پایگاه‌داده، و همین راهنما. از روی همین مخزن، هر پایگاه‌داده‌ای
از نو ساخته می‌شود.

**نیست:** خودِ فایل `.data/muis.sqlite`. داخلش هش رمزها و نشست‌هاست و این مخزن عمومی است؛
commit کردنش یعنی دادن یک ورودی آفلاینِ رایگان برای حدس‌زدن رمزها به هرکس که مخزن را ببیند.
به‌جایش از `bun run backup` استفاده کن و آن فایل را جایی امن نگه دار.

## فرمان‌ها

| فرمان | چه می‌کند |
| --- | --- |
| `bun run dev` | سرور توسعه |
| `bun run build` | بیلد برای استقرار |
| `bun test src` | تست‌ها |
| `bun run lint` | eslint |
| `bun run backup` | نسخه پشتیبان از پایگاه‌داده |
| `bun run restore <file>` | بازگرداندن نسخه پشتیبان |

## استقرار

بیلد، خروجی ورکر Cloudflare می‌سازد:

```bash
bun run build
npx nitro deploy --prebuilt
```

پیش از این، `d1_databases` را در `wrangler.jsonc` پر کن (`npx wrangler d1 create muis`
شناسه را می‌دهد) تا حساب‌ها روی سرور هم کار کنند.
